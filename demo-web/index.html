Pipe Up demo call

A simulated video call with live captions. You are Sam, who stutters and usually speaks for himself. When a block comes at a busy moment, Pipe Up offers a backup: three short replies to post in the chat or have read aloud, generated on this computer when Gemini Nano is available (the badge shows where each one came from). Keys: 1, 2, 3 to pick, Enter to send, Tab to edit, 4 when you answered yourself, Alt+1 for "I'm still speaking".

Source code

This browser can't run Gemini Nano on this computer. Pipe Up normally works fully on-device. To try it here, allow the cloud: the last two caption lines are sent to the Gemini API through Firebase. Sam's briefing is fictional, so this demo also sends the matching excerpts; in the extension that is a separate opt-in.
