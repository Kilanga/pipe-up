Pipe Up demo call

A simulated video call with live captions. Sam stutters and usually speaks for himself; when a block hits at the wrong moment, Pipe Up offers a backup: three short replies to post in the chat, all generated on this computer. Keys: 1, 2, 3 to pick, Enter to send, Tab to edit, 4 when you answered yourself, Alt+1 for "I'm still speaking".

Source code

This browser can't run Gemini Nano on this computer. Pipe Up normally works fully on-device. To try it here, allow the cloud: only the last two caption lines are sent to the Gemini API through Firebase.
