## Pipe Up 0.3.1

Fixes from a full test pass (hosted demo, extension on a test Meet page, and a real Chrome on macOS).

**Fixed**
- Key **4** ("I answered myself") and **Esc** now work even when a button had focus (for example right after clicking in Meet). Esc is left to Meet's dialogs and menus.
- In on-demand mode, and when the side panel is closed, suggestions for an older question are withdrawn when a new one arrives.
- Sending to the Meet chat no longer erases a message you were typing there.
- Typing in Settings is no longer erased when you change a display option before saving.
- *One suggestion at a time* applies at once to the suggestions on screen.
- When the side panel closes during a request, the badge no longer stays on "Thinking…".

**Hosted demo**
- The Pipe Up panel now has its own column, so it never covers the call controls or the chat; the page also works on a phone.

**Install:** download `pipe-up-extension.zip`, unzip, open `chrome://extensions`, enable Developer mode, *Load unpacked* (remove the previous version first).
