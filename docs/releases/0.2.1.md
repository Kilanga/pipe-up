## Pipe Up 0.2.1

Fixes found in a second code review, plus clearer wording.

**Fixed**
- The extension's side panel failed to load in 0.2.0. It works again.
- Shortcuts use the physical key: Alt+1 and 1/2/3/4 now work on AZERTY keyboards and on macOS (Option+1).
- Quick phrases (Alt+1) keep the suggestions on screen and no longer count them as ignored.
- A suggestion opened for editing is withdrawn when a new question arrives, unless you changed it.
- "Voice only" never loses a reply: if the voice cannot play, the reply goes to the chat.
- A stalled or failed request no longer blocks suggestions for the rest of the call (20 s limit).
- The side panel shows the right connection status when you switch tabs.
- Setting up the voice can be retried after a failed download.
- The microphone is only routed through Pipe Up once the voice is set up; Meet sees the real microphone's name and settings; a limiter, a click-free hand-over and one reply at a time.
- Stronger fencing of captions and documents in the prompt.
- Custom quick phrases are kept when upgrading.
- Release builds fail instead of shipping placeholder settings.

**Demo**
- Auto-play plays the whole scripted call.
- *Try with the cloud* also shares Sam's fictional briefing, so grounded replies show without Gemini Nano.

**Install:** download `pipe-up-extension.zip`, unzip, open `chrome://extensions`, enable Developer mode, *Load unpacked*.
